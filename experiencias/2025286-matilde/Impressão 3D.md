# Base de Copos Botão (Impressão 3D)

> Para o projeto desenvolvido na impressora 3D desenvolvi um visual que explora a forma do botão como base para canecas.

![](botaoresultado.png)

## Conceito

Para o projeto desenvolvido na impressora 3D desenvolvi um visual que é persistente no meu dia a dia, compreendendo que um dos meus hobbies é costura e bordar, e explorar a forma do botão. 
O botão surgiu como um decoração para o meu espaço criativo, que ao desenvolver este protótipo no programa Fusion Autodesk percebi que poderia atribuir a funcionalidade de base para canecas, copos e taças pequenas. Uma das coisas mais importantes no meu espaço de trabalho é a comida, é aquilo que me motiva e move, quando estou cansada como, se estou doente ou tenho dores de cabeça bebo chá ou uma caneca de leite quente. Então este botão seria a minha maneira de cuidar de mim mesma, estimulando a vontade de comer e apreciar o momento a partir do visual atrativo e de especial interesse pessoal.
